# auto-judge-rag26

Scripts and data for the rag26-nov classroom annotator: pull the nuggets, grade all
systems, and build the annotation web UI. Everything this workflow produces stays in
this directory. The dataset and the release export are gated; run these yourself.

## Setup

This directory is a self-contained project: `pyproject.toml` declares every dependency
(the annotator, the grading judge, and their local checkouts), so no other project's venv
is borrowed. Build its venv once:

```sh
uv sync
```

The scripts then pick up `./.venv/bin/{python,auto-judge,autojudge-annotate}` automatically
(no activation needed); override `PY` / `AUTOJUDGE` / `ANNOTATE` to point elsewhere.

## Steps

1. **Pull nuggets + build the UI** (and attach grades if they exist):

   ```sh
   EXPORT_CLEAN=<release>/clean/evalbase/runs/autojudge ./make-rag26-nov-annotator.sh
   ```

   Merges every judge's rag26 bank for the four topics into `rag26-nov-nuggets.jsonl`
   (via `python -m autojudge_base.nugget_data.merge`), then generates
   `rag26-nov-annotate.html`. If `rag26-nov-grades/rubric.judgments.jsonl` is present it
   also flattens it to `rag26-nov-nugget-grades.jsonl` (a generated temp intermediate,
   gitignored) and passes that to `--nugget-grades`. The annotator keys both cards and
   grades by `md5(question text)`, so grades attach by content (the bank's own nugget ids
   are not unique across merged submission banks and are not used for matching).

2. **Grade all systems** (rubric prompt of our submission, on the `:2026` proxy):

   ```sh
   ./grade-rag26-nov.sh
   ```

   Needs the merged bank from step 1. Runs the crucible rubric judge from this project's
   venv (the workflow ships inside the installed `trec2026` package) and writes
   `rag26-nov-grades/rubric.judgments.jsonl` here. Set `OPENAI_BASE_URL` to change the
   endpoint; no `CACHE_DIR` (the proxy owns the cache). Check the volume first (runs x 4
   topics x union-nuggets rubric calls, at real cost).

3. **Rebuild the UI** so it picks up the grades:

   ```sh
   EXPORT_CLEAN=<release>/clean/evalbase/runs/autojudge ./make-rag26-nov-annotator.sh
   ```

## Files

| File | Role |
|------|------|
| `pyproject.toml` | the self-contained env (`uv sync`): annotator + grading deps, local sources |
| `rag26-nov-judge.workflow.yml` | judge-only workflow: reuses `CrucibleJudge`, rubric, `bank_label=merged` |
| `make-rag26-nov-annotator.sh` | merge nuggets, flatten grades if present, build the UI |
| `grade-rag26-nov.sh` | grade all systems vs the merged bank (rubric, bank_label=merged) |
| `judgments_to_nugget_grades.py` | flatten `rubric.judgments.jsonl` to the UI's `--nugget-grades` |
| `rag26-nov-nuggets.jsonl` | merged nugget bank (output of step 1) |
| `rag26-nov-grades/` | grading outputs: judgments, eval, run log (output of step 2) |
| `rag26-nov-nugget-grades.jsonl` | TEMP INTERMEDIATE (gitignored): flattened grades for the UI, regenerated by step 1 from the judge dump |
| `rag26-nov-annotate.html` | the annotator web page (output of step 1) |

The per-topic union merge itself lives in the library: `autojudge_base.nugget_data.merge`.
